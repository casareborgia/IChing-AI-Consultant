# 확정 용어표 — 3단계 450건 배치용

파일럿 4벌의 `key_terms` 합집합에서 확정했다. D단계 프롬프트에 이 표가 들어간다.
`桎梏`·`臀`은 사람이 직접 정했고, 나머지는 위임받아 정했다(2026-08-14).

원칙: 표준 독음 우선 → 정전·RUBRIC 근거 우선 → 서로 다른 한자가 같은 우리말로 겹치지 않게.
용언은 기본형, 체언은 명사형으로 표제어를 통일했다.

총 110항목 (고정 15 / 4벌 합의 64 / 갈려서 확정 31)

## 근거를 적어둔 항목

| 한자 | 우리말 | 근거 |
|---|---|---|
| 桎梏 | 질곡 | 사람 지정. 우리말 표준 독음 |
| 臀 | 볼기 | 사람 지정. RUBRIC L47-1이 참조한 표현 |
| 坎 | 감 | 괘명으로 쓸 때 |
| 坎(뜻) | 구덩이 | 뜻으로 쓸 때. 險과 겹치지 않게 나눴다 |
| 行 | 행하다 | 往(나아가다)과 겹치지 않게 |
| 首 | 머리 | 합의된 无咎…无首(머리가 없음)와 맞춤 |
| 寘 | 두다 | 寘于叢棘 — "갇히다"는 해석이 들어간 말 |
| 刑人 | 형벌을 씀 | 정전 威之以刑. "형인"은 뜻이 안 드러난다 |
| 瀆 | 모독하다 | 瀆則不告. "독"은 불투명 |
| 際 | 사귐 | 覿(만나다)과 겹치지 않게 |
| 馴 | 따르다 | 정전 馴致其道 |
