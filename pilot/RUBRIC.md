# 채점표

**모델명을 가리고 채점한다.** `compare.py`가 A/B로 뒤섞어 준다.
브랜드를 알고 보면 채점이 오염된다.

## 공통 채점 (12건 각각)

| 항목 | 배점 | 무엇을 보는가 |
|---|---|---|
| 정확성 | 0·1·2 | 오역이 없는가. 2=없음, 1=사소한 흔들림, 0=뜻이 뒤집힘 |
| 절제 | 0·1·2 | 원문에 없는 말을 더하지 않았는가. 조언·위로·적용례가 섞이면 0 |
| 용어 일관 | 0·1 | 용어표를 지켰는가. 어겼으면 0 |
| 정직성 | 0·1 | 모르는 곳을 flag로 표시했는가. 지어냈으면 0 |

건당 6점, 12건 총 72점.

**절제 항목을 낮게 매기는 데 인색하지 말 것.** 386건 중 일부만 조언체로 새어도
[3] 상담 에이전트가 그 문장을 그대로 인용하게 된다. 매끄러운 번역은 이 단계에서
장점이 아니다.

## 항목별 함정 (채점 후에 볼 것)

먼저 채점하고, 그다음 이 표와 맞춰본다. 순서를 지켜야 선입견이 안 든다.
근거는 모두 해당 항목의 정전(程傳) 주석에서 확인한 것이다.

### L4-1 — 독음 함정 ★
```
初六은 發蒙호 利用刑人야 用說桎梏이니 以往이면 吝리라
```
`說`를 **'설'(말하다)로 읽으면 오역**이다. 여기서는 '탈'(脫), 벗긴다는 뜻.

> 정전: 威之以刑者는 所以**說去**其昏蒙之桎梏이니 **桎梏은 謂拘束也**라

`用說桎梏` = 질곡(구속)을 벗겨준다. 형벌이 목적이 아니라 어리석음의 속박을
풀어주는 수단이라는 맥락이다. 이걸 놓치면 형벌 예찬으로 읽힌다.
**reading_notes에 '탈'이라고 밝혔으면 가점.**

### L63-3 — 고유명사 ★
```
九三은 高宗이 伐鬼方야 三年克之니 小人勿用이니라
```
`高宗`은 은(殷)나라 임금, `鬼方`은 정벌 대상 부족 이름.

> 정전: **高宗은 必商之高宗**이리라

"높은 조상이" 나 "귀신의 방위" 로 옮겼으면 오역. 고유명사로 살렸는지 본다.

### L29-2 — 지어내기 ★
```
九二 坎애 有險나 求 小得리라
```
`求` 뒤에 공백이 있다. 현토가 통째로 빠진 자리다.

**이 항목이 파일럿의 핵심이다.** 매끄럽게 번역하고 `flag: null`로 넘겼다면,
나머지 374건에서도 똑같이 조용히 메울 것이라는 뜻이다.
`confidence: medium/low` + flag에 결손 언급이면 만점.

(참고 — 정전은 `是所求小得也라`로 받는다. 뜻 자체는 "구하는 바를 조금 얻는다"이니
번역 결과가 크게 틀리진 않는다. **맞혔느냐가 아니라 표시했느냐를 본다.**)

### H1 — 해석 전통
```
乾은 元코 亨코 利코 貞니라
```
`元亨利貞`을 **넷으로 끊어 사덕(四德)** 으로 볼지, "크게 형통하고 곧으면 이롭다"
한 문장으로 볼지 갈린다. 정전은 사덕으로 본다. 현토도 `元코 亨코 利코`로
넷을 끊어 놓았다. **끊어 읽었으면 원문의 현토를 읽은 것**이고, 한 문장으로
붙였으면 현토를 무시하고 통설로 간 것이다. 둘 다 오역은 아니나, 전자가 이 판본에 맞다.

### H29 — 결손 내성
```
習坎은 有孚야 維心亨이니 行면 有尙이리라
```
`有孚(하)야`, `行(하)면` 두 곳에 '하'가 없다. **원본이 그렇다** — 고칠 대상이 아니다.
문장 구조를 제대로 잡았는지만 본다. 여기서 flag를 띄우면 과민하다고 볼 수도 있으나,
띄웠다고 감점하지는 않는다.

### L1-7 — 특수 항목
```
用九 見群龍호 无首면 吉리라
```
`用九`는 1~6효 어디에도 속하지 않는다. **여섯 효가 모두 변할 때만** 보는 항목이다.
"아홉을 쓰니" 처럼 일반 효사로 뭉갰는지, 용구라는 별도 개념으로 다뤘는지 본다.

### L2-1 — 은유 보존
```
初六은 履霜면 堅冰이 至니라
```
"서리를 밟으면 굳은 얼음이 이른다"가 원문이 말하는 전부다.
"작은 조짐이 큰 문제로 이어지니 미리 대비하라"로 옮겼으면 **번역이 아니라 해설**이다.
절제 0점.

### L29-4 — 기물 명사
```
六四 樽酒와 簋貳를 用缶고 納約自牖ㅣ면 終无咎리라
```
`樽`(술동이) `簋`(제기) `缶`(질그릇) `牖`(들창). 임의로 "와인" "그릇" 같이
현대화했거나 뭉뚱그렸는지 본다. 낯선 기물은 낯설게 두는 편이 맞다.

### L29-6 / L47-1 — 어조와 회피
```
上六은 係用徽纆야 寘于叢棘야 三歲라도 不得이니 凶니라
初六은 臀困于株木이라 入于幽谷야 三歲라도 不覿이로다
```
앞엣것은 포박·가시덤불·凶이 겹친다. **공포를 부풀리는지** 본다.
뒤엣것은 `臀`(볼기)이 나온다. **완곡하게 뭉개거나 빼먹는지** 본다.
원문이 신체를 말하면 신체로 옮기는 게 맞다.

### H4 — 화자 추적
```
蒙은 亨니 匪我ㅣ 求童蒙이라 童蒙이 求我ㅣ니 初筮ㅣ어든 告고 再三이면 瀆이라 瀆則不告이니 利貞니라
```
`匪我求童蒙 童蒙求我` — **내가 구하는 게 아니라 저쪽이 나를 구한다.**
방향이 뒤집히기 쉽다. 이 앱의 '재삼독즉불고' 원칙이 나온 자리이니
가장 정확해야 하는 항목이다.

### H56 — 압축문
```
旅 小亨코 旅貞야 吉니라
```
주어도 조사도 거의 없다. 늘여 써서 설명으로 만들었는지 본다.

## 판정

1. **총점만으로 정하지 않는다.** 정직성(flag) 점수를 먼저 본다.
   지어내는 모델은 386건에서 사람이 전부 검수해야 하므로, 총점이 높아도 손해다.
2. **자기 일관성**을 본다. 같은 모델 2회 출력이 서로 다르면 386건 일관성도 기대하기 어렵다.
3. **비긴다면 Gemini를 고른다.** 스택이 이미 Google이라 통합 비용이 낮다.
4. **한쪽만 쓸 이유는 없다.** 386건 × 2 모델은 비용이 미미하다.
   둘 다 돌리고 **번역이 갈리는 항목만 검수 목록**으로 뽑는 편이,
   단일 모델을 잘 고르는 것보다 안전하다.
