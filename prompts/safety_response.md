# 안전 응답 템플릿 (Safety Responses)

사용자 화면에 직접 노출되는 안전 안내 문구 템플릿 모음입니다.
내부 판정 라벨(`BLOCK_CRISIS`, `BLOCK_SCOPE` 등)은 절대 사용자에게 노출하지 않습니다.

**이 파일이 실제로 나가는 문구다.** `agents/safety.py`가 각 제목 아래 코드펜스를
읽어간다(`core.prompts.load_prompt_block`). 코드에 같은 문구를 복사해 두지 말 것 —
한동안 그렇게 되어 있었고, 이 파일을 고쳐도 화면에는 아무 변화가 없었다.

펜스 밖의 인용문(`>`)은 사람이 읽는 설명이고 사용자에게 나가지 않는다.

---

## 1. BLOCK_CRISIS (위기 대응 안내)

> **톤 원칙**: '거절'이 아니라 '순서'로 말합니다. 괘를 구하러 온 분에게 차갑게 거절하기보다, 내담자의 안전과 안녕이 지금 가장 우선임을 따뜻하게 안내합니다.

### 기본 템플릿
```
지금 남겨주신 말씀을 그냥 지나칠 수 없었습니다.
혼자 감당하기 어려운 무거운 마음과 순간에는, 주역의 괘를 헤아리기보다 전문가의 따뜻한 손길을 먼저 마주하는 것이 가장 중요합니다.

지금 바로 24시간 언제든 무료로 도움을 받을 수 있는 곳이 있습니다:

* **자살예방 상담전화**: ☎ **109** (24시간 무료)
* **정신건강 위기상담전화**: ☎ **1577-0199** (24시간 무료)
* **청소년 상담전화**: ☎ **1388** (24시간 무료, 청소년 및 보호자)
* **여성긴급전화**: ☎ **1366** (24시간 무료, 가정·성·데이트폭력 피해)

당신의 삶과 안전은 그 어떤 것보다 소중합니다. 잠시 숨을 고르시고, 위의 번호로 마음을 나누어 보시기를 간곡히 권합니다.
```

### 청소년 정황 우선 템플릿 (미성년자/학업/가정 갈등 등)
```
지금 남겨주신 이야기를 들으니 마음이 참 무겁고 힘들었을 것 같습니다.
혼자 끙끙 앓지 않고 도움을 받을 수 있는 전문 선생님들이 기다리고 계십니다.

* **청소년 상담전화**: ☎ **1388** (전화/문자/카카오톡 24시간 무료)
* **자살예방 상담전화**: ☎ **109** (24시간 무료)
* **정신건강 위기상담전화**: ☎ **1577-0199** (24시간 무료)

언제든 편하게 연락해 보세요. 당신의 이야기를 귀 기울여 들어주실 것입니다.
```

### 폭력 피해 정황 우선 템플릿 (가정폭력, 데이트폭력, 성폭력 등)
```
지금 계신 상황의 안전이 매우 염려됩니다.
더 이상 혼자 두려워하거나 견디지 마시고, 즉시 안전한 보호와 법적·심리적 지원을 받으시기 바랍니다.

* **여성긴급전화**: ☎ **1366** (24시간 긴급 보호 및 상담)
* **경찰 긴급신고**: ☎ **112**
* **정신건강 위기상담전화**: ☎ **1577-0199**
```

## 2. BLOCK_SCOPE (상담 범위 밖 안내)

> **원칙**: 위기 핫라인(109 등)을 붙이지 않고, 해당 전문 영역(의료·약물, 법률, 세무, 투자 등)의 전문가와 상의하도록 정중히 안내합니다.

```
질문해 주신 내용은 전문적인 진단과 검토가 필요한 영역(의료/약물, 법률, 세무, 금융 등)에 해당합니다.

주역은 인간의 마음가짐과 삶의 변화를 성찰하는 지혜의 도구이지만, 전문적인 판단이나 치료를 대신할 수는 없습니다. 안전하고 정확한 해결을 위해 해당 분야의 전문 기관이나 전문가(의사, 변호사, 전문 상담가 등)와 상의하시기를 권해드립니다.
```

---

## 3. CAUTION (주의 병행 안내)

> **원칙**: 괘는 정상적으로 도출하여 상담을 진행하되, 심리적 부담이 있는 내담자에게 답변 말미에 부드럽게 덧붙이는 짧은 안내 문구입니다.

*(상담 답변 끝에 덧붙임)*

```
> 💡 *참고 안내: 주역의 괘와 상담 내용은 상황을 바라보는 새로운 관점과 성찰을 돕기 위한 참고 자료입니다. 마음의 큰 부담이나 지속적인 어려움이 있으실 때는 전문 심리상담이나 의료 기관의 도움도 함께 고려해 보세요.*
```

---

## 4. ASK (명확화 되묻기 템플릿)

```
남겨주신 고민을 주역의 괘로 깊이 들여다보기에 앞서, 한 가지 여쭙고 싶은 점이 있습니다.

{ask_question}

생각나시는 대로 편하게 말씀해 주시면, 그 마음의 맥락을 담아 괘를 헤아려 드리겠습니다.
```

---

## 5. SYSTEM_ERROR (일시적 시스템 오류 안내)

> **원칙**: 통신 장애나 시스템 오류 시 위기 핫라인을 띄우지 않고, 잠시 후 다시 시도하도록 차분히 안내합니다.

```
죄송합니다. 서비스 일시적인 연결 지연으로 인해 답변을 정리하는 데 어려움이 발생했습니다.
잠시 후 다시 말씀해 주시거나 새로고침 후 이용해 주시기 바랍니다.
```
